**1. Sending OTP**

+----------------+--------------------------------------------------------------+
| Method         | POST                                                         |
+----------------+--------------------------------------------------------------+
| Test URL       | http://10.128.1.227:8080/SharedService/api/otp/sendOtp      |
+----------------+--------------------------------------------------------------+
| Production URL | (Not Provided in Document)                                   |
+----------------+--------------------------------------------------------------+
| Content Type   | application/json                                             |
+----------------+--------------------------------------------------------------+
| Request Body   | OtpDTO (JSON Object) - Mandatory (See Table 1.1 for fields) |
+----------------+--------------------------------------------------------------+
| Sample Request | {                                                            |
|                |   "mobileNo": "0777212684",                                  |
|                |   "systemName": "New Connection",                            |
|                |   "systemCode": "smc"                                        |
|                | }                                                            |
+----------------+--------------------------------------------------------------+
| Response       | otp (int) - Returns the OTP on success, or -1 on error.      |
+----------------+--------------------------------------------------------------+

***

**2. Validation OTP**

+----------------+--------------------------------------------------------------+
| Method         | POST                                                         |
+----------------+--------------------------------------------------------------+
| Test URL       | http://10.128.1.227:8080/SharedService/api/otp/validateOtp  |
+----------------+--------------------------------------------------------------+
| Production URL | (Not Provided in Document)                                   |
+----------------+--------------------------------------------------------------+
| Content Type   | application/json                                             |
+----------------+--------------------------------------------------------------+
| Request Body   | OtpDTO (JSON Object) - Mandatory (See Table 1.1 for fields) |
+----------------+--------------------------------------------------------------+
| Sample Request | {                                                            |
|                |   "mobileNo": "07121013657",                                 |
|                |   "otp": 243026                                              |
|                | }                                                            |
+----------------+--------------------------------------------------------------+
| Response       | boolean - Returns `true` on success, or `false` on error.    |
+----------------+--------------------------------------------------------------+

***

**Table 1.1: OtpDTO Object Definition**

+-------------+-------------+--------------------------------------------------------+----------------------+
| Field       | Data Type   | Description                                            | Mandatory For        |
+-------------+-------------+--------------------------------------------------------+----------------------+
| mobileNo    | String(10)  | Mobile number to send the OTP to.                      | Both APIs            |
+-------------+-------------+--------------------------------------------------------+----------------------+
| systemName  | String      | Name of the system sending the OTP (e.g., "New         | sendOtp API only     |
|             |             | Connection"). This is included in the SMS message.     |                      |
+-------------+-------------+--------------------------------------------------------+----------------------+
| systemCode  | String      | Code used as a client reference by the SMS gateway.    | sendOtp API only     |
+-------------+-------------+--------------------------------------------------------+----------------------+
| otp         | int         | The OTP code entered by the user for validation.       | validateOtp API only |
+-------------+-------------+--------------------------------------------------------+----------------------+
